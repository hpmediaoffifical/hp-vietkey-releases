# HP VietKey

Bộ gõ tiếng Việt Telex cho Windows 10 / 11. Một file cài đặt nhỏ gọn, không cần quyền quản trị, không cần cài thêm gì.

**[Tải bản mới nhất](https://github.com/hpmediaoffifical/hp-vietkey-releases/releases/latest)**

- **Tác giả:** Nguyễn Hoàng Phụng ([Facebook](https://www.facebook.com/hoangphung.nguyen1809/))
- **Nhà phát triển:** HP Media ([hpvn.media](https://hpvn.media/))

## Cài đặt

1. Thoát UniKey, EVKey hoặc OpenKey nếu đang chạy (hai bộ gõ chạy cùng lúc sẽ làm chữ bị lặp hoặc mất dấu).
2. Tải file `HPVietKey-Setup-<phiên bản>.exe` trong mục Releases, mở lên và bấm **Cài đặt**.
3. Biểu tượng **V** (đỏ) / **E** (xám) hiện cạnh đồng hồ. Bấm `Ctrl + Shift` hoặc bấm vào biểu tượng để chuyển Việt / Anh.

File chưa được ký số nên Windows SmartScreen có thể hiện "Windows protected your PC": bấm **More info** rồi **Run anyway**.

Đã cài rồi thì HP VietKey tự kiểm tra bản mới mỗi ngày và cập nhật bằng một lần bấm.

## Tính năng nổi bật

- Gõ dấu tự do: `nguyenex`, `nguyeenx`, `nguyexen` đều ra "nguyễn".
- Tự phân biệt tiếng Anh: `windows`, `data`, `pass`, `sorry` không bị bỏ dấu nhầm; sửa nhầm thì bấm Backspace.
- Quên chuyển sang V: ở chế độ E, gõ `tooi laf` rồi bấm dấu cách vẫn ra "tôi là".
- Gõ được trong phần mềm chạy quyền quản trị (Photoshop, CapCut, trò chơi...), có cách gửi phím và bảng mã riêng cho từng phần mềm.
- Gõ tắt (nhập được file gõ tắt của UniKey), chèn ngày giờ, viết hoa đầu câu, công cụ chuyển mã TCVN3 / VNI / Unicode.
